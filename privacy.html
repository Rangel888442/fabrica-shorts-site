Privacy Policy

Last updated: 24 November 2026

Fabrica Shorts ("the tool") is a private tool used only by the owner of one YouTube channel to upload their own videos and read their own channel data. The tool uses YouTube API Services. By using the tool, the user agrees to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

What data the tool accesses

  • Basic information about the owner's own YouTube channel (name, ID, public statistics).
  • The owner's own YouTube Analytics reports (for example views and audience retention).
  • Permission to upload videos, titles, descriptions, tags and thumbnails to the owner's channel.

The tool does not access, collect or store data about any other YouTube user or viewer.

How the data is used

Data is used only to upload the owner's videos as private and to show the owner how their videos perform, so future videos can be improved. It is never sold, shared with third parties, or used for advertising.

Where the data is stored

The authorization token is stored only on the owner's personal computer, in user environment variables. Channel statistics may be saved as local files on that computer for analysis. No data is stored on any server operated by the tool. Stored statistics are refreshed or deleted within 30 days.

Cookies

The tool and this website do not use cookies or tracking technologies.

How to revoke access

Access can be revoked at any time from the Google security settings page. After revoking, the tool can no longer access the account, and locally stored data can be deleted by contacting the address below.
